## Опис предметної області
Система Online Store призначена для автоматизації процесів електронної комерції та продажу товарів через веб-платформу. Вона забезпечує каталог товарів, управління кошиком покупок, оформлення замовлень та обробку статусів доставки. Код предметної області (Domain) описує ключові сутності: товари (Products), категорії (Categories), покупців (Customers), кошик (Cart) та замовлення (Orders).
